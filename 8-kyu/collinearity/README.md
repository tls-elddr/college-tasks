<h2><a href=https://www.codewars.com/kata/65ba420888906c1f86e1e680/train/python target="_blank">Collinearity</a></h2><h3>8 kyu</h3><h2 id="theoretical-material"><font dir="auto" style="vertical-align: inherit;"><font dir="auto" style="vertical-align: inherit;">Теоретический материал</font></font></h2><p><font dir="auto" style="vertical-align: inherit;"><font dir="auto" style="vertical-align: inherit;">Вам даны два вектора, исходящие из начала координат (x=0, y=0) с координатами (x1,y1) и (x2,y2). Ваша задача — определить, являются ли эти векторы коллинеарными. Коллинеарные векторы — это векторы, лежащие на одной прямой. Они могут быть направлены в одном или противоположных направлениях. Один вектор можно получить из другого, умножив его на определенное число. В терминах координат векторы (x1, y1) и (x2, y2) коллинеарны, если (x1, y1) = (k*x2, k*y2), где k — любое число, выступающее в качестве коэффициента.</font></font></p><img
